# `rvs` 0.8.0

`rvs` 0.8.0 limits disposable package credentials to the operations required by
each native client invocation. Read commands request read-only credentials,
publishing commands request write-only credentials, and OCI copy requests cover
both sides of the transfer without exposing the long-lived session credential.

Device login sessions now default to 180 days, accept durations from 12 hours to
180 days, and bind browser approval to the duration recorded by the CLI.
