# `rvs` 0.4.0

`rvs` 0.4.0 adds native OCI registry workflows for Ravenstash Container and Helm
repository lanes.

## Added

- `rvs docker` delegates to the installed Docker client with an exact-repository,
  short-lived Ravenstash credential.
- `rvs helm` delegates OCI chart operations to the installed Helm client.
- `rvs oras --rvs-kind container|helm` supports explicit ORAS workflows for either
  Ravenstash OCI profile.
- `rvs oci-reference` prints the stable customer-facing OCI reference without
  exposing the clients' internal Distribution route prefix.
- `docker-credential-rvs` is packaged alongside `rvs` for exact-host credential
  injection.
- Repository discovery/default commands accept the `container` and `helm` kinds.

## Credential behavior

The wrappers resolve one exact customer, workspace, repository, and registry kind.
They copy the native client configuration into a mode-`0600` temporary directory,
install the Ravenstash helper only in that copy, preserve credentials for unrelated
hosts, and remove the temporary directory after the child process exits. The
short-lived capability is not placed in argv or written to the user's Docker or
Helm configuration.

## Compatibility

Container and Helm require the native Docker, Helm, or ORAS executable selected by
the command. OCI upstream caches and classic Helm repositories are not supported.

This is the first release on the `v0.4` APT compatibility channel. Moving an
existing installation from `v0.3` is explicit through `rvs upgrade --to v0.4`;
patch updates within `v0.4` remain automatic.
