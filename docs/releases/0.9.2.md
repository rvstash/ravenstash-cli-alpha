# `rvs` 0.9.2

`rvs` 0.9.2 fixes native Maven downloads through Ravenstash private mirrors.

- read-only mirror targets no longer attempt to resolve a Publisher upload URL;
- generated Maven settings route dependencies and build plugins through the
  selected Ravenstash target with `mirrorOf=*`; and
- deploy and deploy-file commands retain their dedicated authenticated upload
  destinations.

This is a compatible patch on the `v0.9` channel.
