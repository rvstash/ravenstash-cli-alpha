# RVS 0.14.12

RVS 0.14.12 is a security release. It also follows the updated Ravenstash `v0`
developer API.

## A project can no longer redirect your sign-in

Earlier releases read a `.rvs.env` file from the current directory or any
parent directory, and its endpoint settings replaced the Ravenstash API and
registry addresses of every saved profile. A repository you cloned could
therefore send your Ravenstash credentials to another server. RVS 0.14.12:

- no longer reads `.rvs.env` from the working directory; an env file is read
  only when `RVS_ENV_FILE` names it, and it must belong to you and must not be
  writable by group or others;
- applies endpoint settings from the environment only while a profile is being
  created, never to a saved profile, and warns when one is ignored;
- sends a stored sign-in only to the Ravenstash API that issued it.

Update with `rvs update --apply`. If you ever ran `rvs` inside a project you did
not trust, sign out with `rvs auth logout --all` and sign in again.

## Other security fixes

- `rvs auth logout`, `rvs profile delete`, and `rvs profile rename` end the
  session on the Ravenstash server, not only locally.
- Plain HTTP is accepted only for `localhost` and loopback addresses.
- Evidence upload errors no longer print the temporary upload address.
- Text from Ravenstash is shown literally and cannot change terminal
  formatting.
- `rvs mvn` gives the Ravenstash repository a random ID for each run.
- `rvs update` refuses expired or replayed release-channel manifests.

## Developer API update

`rvs` follows the updated `v0` developer API for OCI tags, package-version
files, native registry discovery, private mirrors, upstream sources, and package
evidence. `rvs art oci manifest list` shows each manifest's newest tags and tag
count, `rvs art oci tag list PATH --digest sha256:DIGEST` lists every tag of one
manifest, and `rvs art package show --version` reads every page of a version's
files. Earlier `rvs` releases cannot use these routes, so update `rvs` together
with the Ravenstash update.
