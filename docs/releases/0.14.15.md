# RVS 0.14.15

RVS 0.14.15 is a small update to the status and error output.

## Status shows the profile first

`rvs status` now lists the profile first, followed by who is signed in, because
the profile decides which sign-in and selections apply. With `--json`, the
`profile` key also comes before `signed_in_as`.

## Clearer error messages

Error messages about unexpected API responses name the Ravenstash API.

Update with `rvs update --apply`.
