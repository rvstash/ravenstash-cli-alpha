# `rvs` 0.8.2

`rvs` 0.8.2 treats Maven's standard `deploy-file` goal as an upload operation.
The wrapper now requests an upload-capable package credential and injects the
selected Ravenstash repository's `url` and `repositoryId`, matching its existing
support for the Maven `deploy` lifecycle.

This release also includes the published-installer promotion and verification
keyring fixes prepared after 0.8.1.
