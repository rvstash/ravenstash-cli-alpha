# RVS 0.14.6

RVS 0.14.6 makes the stable-release graph easier to inspect without changing
its publication barriers.

Installer-policy publication, release validation and channel signing,
installer deployment, and recommended-channel publication now appear directly
as jobs in the main release workflow. Their protected `apt-storage`,
`apt-signing`, and `installer-delivery` environments remain separate, and the
safe jobs continue to run in parallel.

The unused standalone promotion workflow has been removed. Promotion now also
requires the published source identity to name the current release run exactly,
which removes the obsolete recovery-workflow provenance compatibility path.
