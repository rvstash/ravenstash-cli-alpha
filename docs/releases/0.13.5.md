# RVS 0.13.5

RVS 0.13.5 adds interactive account switching and makes repository listings
more compact and precise. `rvs account switch` can select personal and
organization accounts interactively, account output consistently uses public
handles, and repository tables identify repositories as `namespace/name`
without redundant account columns.

Authentication session refresh now reuses the existing HTTP client connection.
Invalid local configuration produces a concise recovery message rather than a
Python traceback, and runtime dependencies use reviewed exact pins shared with
the Nix package definition.

The development pipeline now presents one path-aware CI run with parallel
affected checks and a single aggregate gate. Maintainers can create unsigned,
seven-day test builds from exact commits without publishing a release candidate.
Release candidates and stable releases continue through the manually dispatched
release workflow and its full native-platform certification and signing gates.

Release artifacts include the Apache-2.0 license, project notice, runtime
dependency license metadata, and a corrected runtime SBOM.
