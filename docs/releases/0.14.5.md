# RVS 0.14.5

RVS 0.14.5 shortens the stable-release critical path without weakening its
publication barriers.

The workflow now prepares the immutable GitHub draft while the signed APT state
publishes and verifies. Before making that draft public, it re-authenticates the
release identity, notes, source commit, release kind, and SHA-256 digest of every
asset. After publication, portable update-policy delivery runs in parallel with
installer-promotion validation and signing. Installer deployment waits for both,
and the recommended-channel manifest is still published only after the exact
installer bytes are live and verified.

Successful release and promotion handoffs now share one final cleanup stage.
The separately dispatchable promotion workflow remains available for verified
re-promotion or recovery.
