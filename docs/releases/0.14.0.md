# RVS 0.14.0

RVS 0.14.0 is a coordinated breaking update to Ravenstash's internal repository
native routes. Read, publish, browser-transfer, and OCI endpoints now use the
ID-based target `in/ar_...`. The former namespace-qualified
`in_.../ar_...` form is rejected rather than redirected or translated.

The namespace still owns the repository and remains part of discovery,
authorization, expected-target protection, and the name-based target
`{namespace_name}/{repository_name}`. Removing it from the native URL
does not broaden access. RVS validates the current namespace snapshot and exact
repository before it injects a temporary credential or launches a native tool.

This release raises the local configuration format to schema 6 and deliberately
does not migrate schema 5. After upgrading, run `rvs auth login`, select the
account again, and run `rvs art select {namespace_name}/{repository_name}`. Any
manual package-client configuration must be regenerated with `rvs art native
config TOOL` or updated to the new `in/ar_...` URL.
