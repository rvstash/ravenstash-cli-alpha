# `rvs` 0.8.6

`rvs` 0.8.6 routes supported npm metadata mutations through Ravenstash's push
registry instead of the read-only download host.

- `npm unpublish` and `npm deprecate` now request both download and upload
  capabilities and use the configured npm push endpoint.
- mutating `npm dist-tag` operations and the `npm tag` alias use the same
  push-endpoint contract, while read-only `npm dist-tag ls` stays on the download
  endpoint.
- native npm publish behavior is unchanged.

This maintenance release stays on the `v0.8` compatibility channel.
