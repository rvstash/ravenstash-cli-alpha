# RVS 0.14.3

RVS 0.14.3 makes the top-level command reference easier to scan. The
`rvs --help` output now groups native tool wrappers into Python, Node.js, JVM,
container, and Helm sections. Artifact management, account configuration, and
setup commands appear in their own sections, with commands ordered
alphabetically within each group.

This is a documentation-only presentation change: existing command names,
arguments, shell completion, and invocation paths remain compatible.
