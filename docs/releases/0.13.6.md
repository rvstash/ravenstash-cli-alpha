# RVS 0.13.6

RVS 0.13.6 refreshes and exactly pins the runtime, development, build, and
release dependency graph. The CLI now uses HTTPX2 in place of HTTPX while
preserving its existing authenticated API behavior, session refresh, runtime
downloads, and update verification.

Nix packages now resolve the same committed `uv.lock` used by the other build
paths. This removes the independently maintained Nix dependency list and keeps
Linux and macOS Nix builds aligned with the tested Python environment. The
release bundle and SBOM metadata recognize the updated HTTP client and trust
store dependencies.

Candidate verification now requests machine-readable Debian package metadata,
so `rvs update --candidate VERSION` validates the package name, prerelease
version, and architecture consistently across supported `dpkg-deb` versions.
