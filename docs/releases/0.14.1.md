# RVS 0.14.1

RVS 0.14.1 extends signed self-update support to portable installations on
Linux with glibc, Alpine/musl, macOS, and Windows. The CLI authenticates the
release inventory, selects the exact operating-system and architecture bundle,
checks its digest and embedded version, and stages it before activation.

Portable POSIX installations activate versions through an atomic `current`
pointer. Windows completes the verified replacement after the running CLI
exits. Both retain the previous version for rollback. The installer records a
non-secret receipt so later updates preserve the original target, release
series, install root, scope, and command directory.

Nix, Homebrew, and WinGet installations remain owned by their package manager;
`rvs update --apply` delegates replacement instead of modifying those files
directly. Availability through Homebrew or WinGet depends on the corresponding
external catalog containing the requested release.

Repository output and help now consistently distinguish the human-readable
`namespace/repository` target from the permanent `in/ar_...` ID-based target.
Private test builds also keep every release identity surface aligned while
running the full Alpine/musl suite.
