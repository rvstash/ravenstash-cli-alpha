# RVS 0.14.14

RVS 0.14.14 is a bug-fix release. It hardens release verification, makes the Docker
credential helper follow the Docker protocol, and fixes Node.js runtime
selection and two update problems on Windows.

## Release verification

`rvs update` rejects a release signature whose armor contains non-ASCII text as
invalid instead of stopping with an internal error. Signature checks still fail
closed on any malformed input.

## Docker credential helper

`docker-credential-rvs` now follows the Docker credential-helper protocol:

- errors are written to stdout, where Docker reads them;
- a registry other than the one the current `rvs` command serves gets the
  standard "credentials not found" answer, so Docker continues without
  credentials and prints no stray message; and
- failures report a fixed message without file paths or parser details.

## Node.js runtimes

`rvs runtime install node latest` installs the newest Node.js release instead of
failing. A version that does not exist, such as `22.99`, is now reported instead
of silently installing another release of the same major version.

## Updates on Windows

- `rvs update` recognizes installations made with winget.
- A second `rvs update` started while one is running reports that an update is
  already in progress instead of failing with a file error.

Update with `rvs update --apply`.
