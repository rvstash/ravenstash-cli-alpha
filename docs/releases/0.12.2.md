# RVS 0.12.2

This corrective release preserves the public artifact repository reference
contract introduced in 0.12.1: repository references use the `ar_` prefix and
eight lowercase unambiguous characters, and retired reference shapes are not
accepted or emitted.

RVS continues to expose one repository OCI lane through both Container and Helm
native clients. A single OCI host credential therefore authorizes both formats
without separate repository lanes.

Version 0.12.2 corrects the release workflow so its public Ubuntu 20.04 ARM64
installation check materializes the trusted Ravenstash APT keyring before
mounting it into the verifier. It also retains the architecture-aware APT index
generation corrections shipped while preparing 0.12.1. The 0.12.1 GitHub
release and installer promotion were withheld when that ARM64 verification
failed; 0.12.2 is the replacement release on the `v0.12` compatibility channel.
