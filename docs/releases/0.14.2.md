# RVS 0.14.2

RVS 0.14.2 fixes portable installation on Alpine Linux. Alpine's musl `ldd`
prints valid libc identification but returns a nonzero status for its unsupported
`--version` option. The installer now inspects that diagnostic independently of
the command status and selects the signed musl bundle correctly.

This restores the intended install and self-update path for x86-64 and ARM64
Alpine systems.
