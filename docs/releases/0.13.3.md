# RVS 0.13.3

RVS 0.13.3 makes update status clearer and improves cleanup when a configured
credential store is temporarily unavailable.

`rvs update` now reports both the installed version and the latest version in
the active release series before confirming that the CLI is up to date.
Credential cleanup continues across the remaining supported stores when one
store raises an operating-system availability error.

The release pipeline now builds eight platform targets independently, assembles
one immutable attested candidate, and publishes that exact candidate without
rebuilding it. Linux packages for amd64 and arm64 are appended and signed in one
pass, while post-publication verification runs on both architectures in
parallel.
