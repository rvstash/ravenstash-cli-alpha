# `rvs` 0.8.11

`rvs` 0.8.11 introduces the internal namespace target contract for Ravenstash
package repositories.

- repository selectors accept `namespace/repository` and the explicit
  `internal:namespace/repository` form;
- the future `global:` realm is recognized and fails with a stable unavailable
  response until global namespaces launch;
- stable repository identity uses `in_.../r_...`, while `gn_...` is reserved for
  future global namespaces and `w_...` is rejected at runtime;
- version 1 configuration is migrated atomically to version 2 before the first
  API request, with an owner-only one-time backup;
- malformed, conflicting, or future configuration fails before replacement;
- target ambiguity reports safe customer references and requires explicit account
  selection; and
- immutable selected targets follow authorized renames while deletion or lost
  authority fails closed without falling through to a same-named repository.

This maintenance release stays on the `v0.8` channel.
