# `rvs` 0.8.10

`rvs` 0.8.10 makes direct upgrades from the 0.7 series safe and repeatable.

- versioned configuration migrations run even when an intermediate 0.8 release was
  skipped;
- legacy `cache_base_url` entries are converted once to `mirror_base_url`, and
  conventional `cache.{kind}` hosts are rewritten to `mirror.{kind}` before the
  migrated configuration is atomically persisted;
- normal runtime parsing remains strict and does not support the retired cache
  endpoint names;
- configurations from unknown future versions and missing migration paths fail
  closed without partially updating local state;
- login restores credential state when migrated configuration validation fails;
  and
- APT installation redirects installer-owned legacy portable command links to the
  packaged commands so an older CLI cannot continue shadowing the upgraded binary.

This maintenance release stays on the `v0.8` channel.
