# RVS 0.14.10

RVS 0.14.10 explains a common cause of "not found" errors in automation.

## Token scope hints

Automation tokens can be limited to selected repositories and formats, and
Ravenstash hides every repository and format a token does not cover instead of
revealing that it exists. When `RVS_TOKEN` is set and a repository or one of its
formats is reported as missing, `rvs` now adds:

```text
Check that RVS_TOKEN includes this repository and the npm format.
```

The hint appears for repository resolution, native package-tool wrappers, and
`rvs art token mint`. It never reveals whether the repository exists. Private
mirrors and formats that do not apply to the selected target get no hint, and
interactive device-login sessions are unaffected.
