# `rvs` 0.9.0

`rvs` 0.9.0 makes refresh-backed authentication safe for concurrent native
package-client commands.

- refresh-token rotation is serialized per profile across `rvs` processes;
- a process waiting for another refresh reuses the winning process's new access
  token instead of submitting the now-consumed refresh token;
- refreshed credentials are persisted in crash-safe order, with the new refresh
  token stored before its access token; and
- transient refresh-service failures no longer erase otherwise recoverable
  credentials.

This release starts the `v0.9` compatibility channel. Existing installations
remain on their current pre-1.0 minor channel until the operator explicitly runs:

```console
rvs upgrade --to v0.9
```
