# RVS 0.14.13

RVS 0.14.13 shows who and what a command acts for, lets CI tokens act for their
own account, and tells you when to update `rvs` before the Ravenstash API stops
supporting it. It follows the updated Ravenstash `v0` developer API.

## See who is signed in and what `rvs` targets

`rvs status` shows who is signed in, the profile, the acting account, the
selected Artifacts target, and the Ravenstash API. `rvs art status` shows the
account, repository or mirror, and format that `rvs art` commands use. Both only
read; they never select or save anything.

`rvs context current`, `rvs account current`, and `rvs art current` are removed.
Use `rvs status` or `rvs art status` instead.

People and accounts are now shown by public handle and name, such as
`user:ada (Ada Lovelace)` or `org:acme (Acme Inc)`, instead of by email.
`rvs auth whoami` names the kind of access token in use, `rvs account list` adds
a name column, and a selected repository is shown as `repo:NAMESPACE/REPOSITORY`,
including in publish confirmations and `--json` output.

## Access tokens act for their own account

With a personal access token or an organization automation token in
`RVS_TOKEN`, commands act for the account that owns the token, so CI jobs no
longer need `RVS_ACCOUNT_REF` or `rvs account switch`. A saved or shell
selection does not apply while the token is set, and an `RVS_ACCOUNT_REF` that
names another account stops the command with an explanation.

## Know when to update `rvs`

When Ravenstash deprecates an API this release uses, commands keep working and
print one warning on stderr with the date the API stops working. Stdout, JSON
output, and native tool output are unchanged.

Once Ravenstash no longer supports an API this release uses, every command,
including sign-in refresh and package-tool wrappers, stops with a message to
update `rvs` and exit status 1 instead of failing obscurely. `rvs auth logout`,
`rvs profile delete`, and `rvs profile rename` still remove local credentials
first. Run `rvs update` to check for a newer release.

## Other changes

- Refreshing a sign-in waits and retries when Ravenstash is briefly busy and
  says how long to wait.

Update with `rvs update --apply`. This release needs the matching Ravenstash
update; update `rvs` together with it.
