# RVS 0.14.4

RVS 0.14.4 removes the remaining pre-release compatibility paths now that the
CLI has a clean public baseline.

Repository selection is unified around `rvs art select`. The per-ecosystem
`rvs art repo defaults` and `rvs art repo set-default` commands, the
`rvs art repo create --default` option, and their configuration fallback are no
longer available. Native package-manager wrappers use the selected artifact
target or an explicit `--rvs-target` value.

The hidden `rvs account use` alias has also been removed; use
`rvs account switch`. Release automation now accepts source commits from
`main` only and authenticates artifacts produced by the current release
workflow signer.
