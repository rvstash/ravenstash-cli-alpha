# `rvs` 0.8.9

`rvs` 0.8.9 completes the private-mirror URL cutover.

- native registry discovery requires `mirror_base_url`;
- profile loading no longer accepts the former endpoint key; and
- repository-domain detection recognizes only the canonical `mirror.{kind}`
  hostname family.

This maintenance release stays on the `v0.8` channel.
