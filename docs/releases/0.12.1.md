# RVS 0.12.1

This release adopts the current public artifact repository reference contract,
including `ar_` repository references with eight lowercase unambiguous
characters. Retired repository reference shapes are not accepted or emitted.

The artifact command surface now uses `rvs art`, explicit format selectors, and
native package-manager passthroughs. It adds package lifecycle and OCI management
commands and supports one repository OCI lane through both Container and Helm
native clients. A single OCI host credential can therefore authorize both
formats without creating separate repository lanes.

Version 0.12.1 remains on the `v0.12` compatibility channel. Existing 0.12
installations receive it as a patch update.
