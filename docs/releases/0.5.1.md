# `rvs` 0.5.1

`rvs` 0.5.1 makes repository commands and OCI wrappers emit readable namespace
and repository names while retaining immutable references as accepted input.

## Changed

- Package repository URLs now use the selected namespace and repository names.
- `rvs oci-reference`, Docker, ORAS, and Helm wrappers now use the same readable
  route form.
- Exact registry endpoints discovered from DevAPI remain attached to the active
  profile, including staging and other non-production environments.

## Compatibility

Immutable namespace and repository references remain valid for existing scripts
and saved URLs. Renaming a namespace or repository changes newly emitted readable
URLs; use immutable references when a route must survive renames.

This patch remains in the `v0.5` compatibility channel, so existing `0.5.x`
installations receive it through the normal channel upgrade path.
