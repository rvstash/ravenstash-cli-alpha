# `rvs` 0.9.1

`rvs` 0.9.1 completes the internal-namespace credential cutover for package
and OCI clients.

- remote mirror credential requests use the canonical namespace and repository
  unique-reference fields expected by DevAPI and Pkg;
- OCI wrappers accept the authoritative friendly and stable routes of the same
  exact repository while continuing to reject every unrelated repository; and
- explicit `internal:namespace/repository` targets work consistently with
  Docker, ORAS, Helm, and `rvs oci-reference`.

This is a compatible patch on the `v0.9` channel.
