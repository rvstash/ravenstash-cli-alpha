# RVS 0.13.2

RVS 0.13.2 fixes the clean-start recovery path introduced with the version 5
configuration baseline.

`rvs profile delete --all` now works even when the existing configuration
predates version 5. The command removes credentials for every discovered profile
from all supported local credential stores, replaces the stale configuration
with an empty version 5 configuration, and resets shell-session selection state.
