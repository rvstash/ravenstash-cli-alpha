# RVS 0.14.8

RVS 0.14.8 moves `rvs` to the product-grouped Ravenstash developer API. It
requires the product-grouped service and does not work against a service that
serves only the former routes. Once the service moves, releases 0.10 through
0.14.7 report "This rvs release uses a retired API route. Upgrade rvs." and stop
working; upgrade to 0.14.8 then.

## Product-grouped developer API

Every request now uses one API generation and one owning group:

- sign-in, identity, accounts, and namespaces use `/v0/platform/`; and
- repositories, packages, upstreams, OCI management, private mirrors,
  short-lived tokens, and package evidence use `/v0/artifacts/`.

Short-lived native tokens are minted on the target itself: a repository token
for one or more of its formats, including OCI, or a read-only token for one
private mirror. The token operations are `read`, `publish`, and `delete`;
`rvs art token mint --access read|publish|admin` requests `read`,
`read + publish`, and `read + publish + delete` respectively.

## Native registry discovery

Sign-in no longer returns native registry addresses. After `rvs auth login` and
after each session refresh, `rvs` reads the public Artifacts metadata endpoint
and updates the profile's saved registry addresses when they changed. If that
request fails, the saved addresses stay in place and the command continues;
`rvs auth login` prints a warning in that case. The local configuration format is
unchanged.

## Upstream positions

A repository's package sources are addressed by their fixed position:

```bash
rvs art repo upstream list platform/packages pypi
rvs art repo upstream update platform/packages pypi 2 --position 4
rvs art repo upstream remove platform/packages pypi 4
```

Scripts that passed a source ID to `update` or `remove` must pass the position
shown by `upstream list` instead.

## Package evidence

Evidence commands resolve `--target` to the repository's permanent ID before
calling the API. `rvs art evidence list` returns intents of every package format
in the repository and shows each intent's format; `--format` is now optional.

## Machine-readable output

Commands that print API objects with `--json` follow the new field names:

- evidence intents use `ref`, `repository_ref`, and `package_name`;
- OCI paths and manifests no longer include `format`;
- `rvs art repo upstream list --json` rows contain `position`, `type`, `source`,
  and `source_ref`, and no longer contain `id`; `type` is `repository` or
  `remote_cache` instead of `private` or `remote`, and `source_ref` is `-` for
  a private mirror you cannot see.

Review scripts that parse these fields before upgrading.

## Private mirrors

`rvs art mirror show`, `set-age`, and `delete` address a private mirror only by
its `rc_...` permanent ID. Their `--account` options, and the `--format` option
of `set-age` and `delete`, are hidden and ignored so existing scripts keep
working. `rvs art token mint` rejects a mirror token issued for a different
mirror or format.

## Installer

`install.sh` no longer installs portable releases older than 0.14.7 through
`RVS_INSTALL_VERSION`; those releases predate the rolling `v0` channel.
