# RVS 0.14.17

RVS 0.14.17 names repository access consistently in human-readable and JSON
output. It is the final release from the public alpha repository before the CLI
moves to its final repository.

## Repository access

`rvs art repo list` now reports access as Reader, Publisher, Maintainer, or
Admin. Maintainers can delete versions and manage upstreams, security, and
access, but they cannot change repository settings or delete the repository.
This access level was previously shown as Admin. The `access` value in JSON
output uses the same names.

Update with `rvs update --apply`.
