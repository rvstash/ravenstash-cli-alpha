# `rvs` 0.5.0

`rvs` 0.5.0 moves the repository minimum-package-age contract from days to
hours and adopts the new 24-hour remote-cache default.

## Changed

- Repository and remote-cache commands now use `--min-age-hours` and
  `--max-age-hours` exclusively.
- `rvs pkg repo set-upstream` defaults remote upstreams to 24 hours.
- Private-repository upstreams remain disabled by default and are represented
  as 0 hours at the CLI boundary.
- Resource payloads and human-readable output now use `min_age_hours` and
  `max_age_hours`.

## Compatibility

This release starts the `v0.5` APT compatibility channel because the CLI/API
field and option names changed in place. Existing `v0.4` installations must opt
in explicitly:

```bash
rvs upgrade --to v0.5
```

Profiles, credentials, selected accounts, and selected package targets remain
compatible.
