# `rvs` 0.7.1

`rvs` 0.7.1 completes the private-mirror terminology cleanup introduced in
0.7.0. Mirror listings and detail views now describe absent package-age bounds as
“No minimum” or “No maximum” instead of rendering ambiguous `none hours` values.

The removed `rvs pkg cache` and `rvs pkg remote-cache` compatibility command
groups remain unavailable. Use `rvs pkg mirror` for authenticated private-mirror
operations.
