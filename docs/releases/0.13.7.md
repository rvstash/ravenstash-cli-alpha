# RVS 0.13.7

RVS 0.13.7 makes native registry endpoint discovery more useful for repository
setup. `rvs art endpoint --format FORMAT` now prints labeled read and publish
addresses when the selected target is a repository. Read-only mirrors continue
to show only their read address.

Scripts can request the previous single-value form explicitly with
`--access read` or `--access publish`. JSON output keeps the existing read
fields and adds `publish_endpoint` when publication is available.
