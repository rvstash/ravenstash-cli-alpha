# RVS 0.11.0

Artifacts command identity is now final: use `rvs art` or `rvs artifacts`, with
repository management under their `repo` subgroup. The temporary, deprecated
`rvs pkg` alias has been removed. Top-level `rvs repo` remains unavailable.

Both permanent aliases invoke the same commands and preserve JSON output.
Existing version-3 profiles, selected targets, account identifiers and stored
device credentials are unchanged. Native PyPI/npm/Maven and Docker/Helm/ORAS
wrappers retain their existing behavior.

Removing an old command is a compatibility boundary: this release uses the
`v0.11` APT channel. Existing `v0.10` installations do not cross that boundary
automatically; upgrade explicitly with `rvs upgrade --to 0.11`.

Publication and default-installer promotion require successful deployed QA
against the coordinated Artifacts/DevAPI release. Local release preparation
does not itself imply production certification or channel promotion.
