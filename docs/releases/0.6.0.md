# `rvs` 0.6.0

`rvs` 0.6.0 improves profile endpoint isolation and local-development
compatibility while preserving the registry routes supplied during login.

## Changed

- Profiles retain the exact read, push, cache, and OCI endpoints returned by
  DevAPI.
- Replacing a redirected authenticated profile revokes its previous refresh
  credential against the API origin that issued it.
- Loopback registry endpoints retain their distinct ports and paths while using
  the literal `localhost` host.
- Failed login attempts no longer replace the API origin saved in a profile.

## Compatibility

This release starts the `v0.6` compatibility channel. Existing installations
must opt in explicitly:

```bash
rvs upgrade --to v0.6
```

Profiles and credentials remain compatible. Repository endpoints are refreshed
from DevAPI after the next successful login.
