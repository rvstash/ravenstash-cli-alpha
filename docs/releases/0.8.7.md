# `rvs` 0.8.7

`rvs` 0.8.7 routes every native npm dist-tag operation through Ravenstash's
Publisher endpoint, including the read-only `npm dist-tag ls` command.

- dist-tag listing now uses the same authenticated registry endpoint as add and
  remove, matching Ravenstash's current native npm route topology.
- the command requests the combined package capability required by that endpoint.
- npm install, view, publish, and unpublish routing is unchanged.

This maintenance release stays on the `v0.8` compatibility channel.
