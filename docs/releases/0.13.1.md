# RVS 0.13.1

This patch establishes config version 5 as the first supported public profile
format and prepares the CLI for explicit, sequential config migrations in future
releases. No migration is registered in 0.13.1, and version 5 remains the current
format.

Pre-release config formats older than version 5 are rejected with instructions
to reconfigure. Configs written by a newer CLI are also rejected without being
changed. Future registered migrations will validate the complete migrated config
before atomically replacing it and will retain an owner-only backup of the source
file.

The release remains on compatibility channel `v0.13` and otherwise retains the
platform and command-line distribution coverage of 0.13.0.
