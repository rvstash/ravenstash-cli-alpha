# RVS 0.14.9

RVS 0.14.9 fixes update checks on APT installations.

## Update checks see new releases immediately

`rvs update` previously compared the installed package with APT's cached
package list. Until `sudo apt-get update` ran, a new release stayed invisible and
the command reported "You are up to date". It now checks the signed `v0` release
channel, the same authenticated manifest portable installations use, and reports
the newest release even when the local package list is out of date. If that
channel cannot be read, the check falls back to APT's local list and says so.

## Scoped APT refresh

`rvs update --apply` now refreshes only the Ravenstash APT source before
installing. An unrelated broken or slow APT source no longer blocks an rvs
update, and other sources keep their cached package lists. The package is still
installed by APT, which verifies it against the Ravenstash signing key. If APT
does not offer the signed release after the refresh, for example because of an
APT pin, a hold, or a mirror that has not synchronized yet, the command stops
and explains why instead of installing a different version.

## Upgrading from 0.14.7 or 0.14.8

Earlier releases still read the cached list, so refresh it once:

```bash
sudo apt-get update
rvs update --apply
```
