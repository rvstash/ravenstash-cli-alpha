# `rvs` 0.8.8

`rvs` 0.8.8 makes private-mirror terminology canonical throughout native
package discovery, configuration, command output, and credential routing.

- newly discovered endpoints use `mirror_base_url` and the canonical
  `mirror.{kind}.rvsta.sh` hosts;
- existing profiles containing `cache_base_url` remain readable and are migrated
  to `mirror_base_url` the next time the profile is saved; and
- legacy `cache.{kind}.rvsta.sh` URLs remain recognized as Ravenstash hosts while
  operators migrate package-manager configuration.

This maintenance release stays on the `v0.8` compatibility channel.
