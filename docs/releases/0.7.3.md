# `rvs` 0.7.3

`rvs` 0.7.3 hardens native package-manager execution. Short-lived package
credentials are renewed for each invocation and remain scoped to the selected
repository. npm isolate mode now supplies distinct empty user and global config
files, preserving isolation while remaining compatible with npm 11's duplicate
configuration guard.

Unfiltered `rvs repo list` requests now omit unset query parameters instead of
serializing empty values, restoring compatibility with the production API's
strict optional-filter validation.
