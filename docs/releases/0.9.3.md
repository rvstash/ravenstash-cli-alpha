# `rvs` 0.9.3

This is the Artifacts command transition release on the `v0.9` channel.

- `rvs art` and `rvs artifacts` are permanent, equivalent product groups.
- Repository management lives under `rvs art repo` (or `rvs artifacts repo`).
  The former top-level `rvs repo` shortcut is removed.
- `rvs pkg` is hidden and prints a deprecation warning. It is retained only for
  this transition release and will be removed in 0.9.4.
- Existing profiles, credentials, selected accounts, and repository/mirror targets
  are retained; the product rename does not require signing in again.

This release also includes the separately reviewed publishing changes: format-aware
confirmation replaces interactive shell prompts, and `rvs shell` is removed.
The explicit runtime shell-setup command remains available.
