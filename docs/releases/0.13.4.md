# RVS 0.13.4

RVS 0.13.4 aligns user-facing CLI guidance with Ravenstash's unified OCI
repository model and exercises the simplified end-to-end release pipeline.

Command help and examples now describe `oci` as the repository format for both
container images and Helm charts. ORAS relies on the artifact manifest for its
content type instead of presenting separate Container and Helm format choices.

One manually dispatched workflow now owns the complete release graph. It checks
that all required gates passed on the exact source commit, builds eight native
targets in parallel while restoring authenticated APT state, assembles and
attests one immutable inventory, signs and publishes APT once, verifies both
Debian architectures in parallel, and creates the GitHub release without a
second dispatch or an external candidate run ID.

Top-level Actions runs now use distinct purpose-first names, so source checks,
platform checks, release policy, certification, and publication remain easy to
identify in the combined GitHub Actions view.
