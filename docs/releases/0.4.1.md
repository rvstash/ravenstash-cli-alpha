# `rvs` 0.4.1

`rvs` 0.4.1 corrects repository summaries for logical repositories that combine
package-release and OCI registry kinds.

## Fixed

- `rvs repo show` reports package counts and version counts separately from OCI
  paths and manifests.
- Older DevAPI responses remain compatible: absent OCI counters are displayed as
  zero until the corresponding service rollout completes.

## Compatibility

This maintenance release stays on the `v0.4` APT compatibility channel. Docker,
Helm, and ORAS credential injection and delegation are unchanged.
