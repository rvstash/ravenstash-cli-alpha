# RVS 0.14.11

RVS 0.14.11 follows the final Ravenstash `v0` developer API and leaves
danger-zone operations to the Ravenstash web app.

## Web-app-only operations

Renaming or deleting a repository, adding, editing, or removing a repository's
package sources, changing a private mirror's package-age policy, deleting a
private mirror, and deleting a whole package are no longer `rvs` commands. They
are irreversible or change the sources every build resolves from, so they are
managed in the web app behind its confirmations. The removed commands are:

```text
rvs art repo rename          rvs art mirror set-age
rvs art repo delete          rvs art mirror delete
rvs art repo upstream add    rvs art package delete
rvs art repo upstream update
rvs art repo upstream remove
```

`rvs` still lists and shows repositories, package sources, and mirrors, creates
repositories and mirrors, deletes single package versions and OCI content, and
yanks or deprecates versions.

## Package commands use the selected repository

`rvs art package` commands act on the repository chosen with `rvs art select`
when `--target` is omitted. `--format` is needed only when that repository has
more than one of PyPI, npm, and Maven; yank and unyank always use PyPI, and
deprecate and undeprecate always use npm:

```bash
rvs art select platform/packages
rvs art package list
rvs art package show requests
rvs art package yank requests 2.0.0 --reason "broken wheel"
```

## Package versions

`rvs art package show` prints the package summary and its newest 50 versions and
says when more exist. Use `--limit N` (1–100), `--all-versions`, or
`--version VERSION` for one version with its files and every file digest. With
`--json`, it prints one document with `package`, `versions`, and
`versions_next_cursor`.

## Listings, retries, and errors

Listings such as `rvs art repo list`, `rvs art package list`, and
`rvs account list` read every page. Read commands wait and retry when Ravenstash
asks them to slow down or is briefly unavailable, and errors print as a code and
a message.

## Compatibility

RVS 0.14.11 requires the final `v0` developer API, and earlier `rvs` 0.14
releases cannot use every command against that API. Update `rvs` to 0.14.11
with `rvs update --apply`.
