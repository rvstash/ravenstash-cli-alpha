# RVS 0.13.0

This release reduces the memory and startup cost of common CLI entry points.
Exact `rvs --version` and `ravenstash --version` requests now use a lightweight
entry point, while native package-manager and OCI commands defer their heavier
runtime imports until those commands run. The packaged Linux CLI's measured
peak memory for `--version` fell from about 54 MiB to 34 MiB in local release
testing, with startup time falling from about 0.57 seconds to 0.22 seconds.

Version 0.13.0 also makes the command-line Windows installer available through
`https://ravenstash.com/install.ps1`. Its release promotion workflow verifies
the immutable release source independently from the current installer-delivery
policy, allowing reviewed delivery fixes to promote an already published
release safely.

The release remains distributed through command-line installers, signed APT
packages, portable archives, and Nix. Apple notarization and Windows
Authenticode signing remain deferred.
